# Benchmarks

Benchmark data is generated using [ecraven's r7rs-benchmarks](https://ecraven.github.io/r7rs-benchmarks/).

Results were run on an AMD Ryzen 9 5900X 12-Core Processor running Ubuntu 25.10 (Linux 6.17.0-23-generic).

Lower runtime is better. The summary and table report how many times faster or slower Hawk is than Chez. The graph uses a log2 scale, so equal speedups and slowdowns are the same distance from parity. Results are sorted from faster to slower.
